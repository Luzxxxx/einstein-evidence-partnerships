Run your own analysis.

This public demo replays real saved results and makes no new model requests. Run the full application locally with your own API key. Tested with Node 24, pnpm 11.25 and Windows.

pnpm install --frozen-lockfile --ignore-scripts
pnpm setup:data
pnpm build:server
pnpm build:web
pnpm demo

For new analyses, copy config/gateway.env.example to .env.local, configure your provider, then start dist/server/server/main.js with Node's --env-file-if-exists=.env.local option.

What is verified?

Three development pairs passed the source, review and publication checks. The dataset is the official synthetic EINSTEIN corpus. These are proposed pilots, not proven business outcomes. There are no human relevance labels or accuracy claims; held-out cases remain unopened. Source verification checks the cited bytes and identity, not semantic truth by itself.
